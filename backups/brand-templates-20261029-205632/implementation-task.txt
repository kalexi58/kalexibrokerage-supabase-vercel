FEATURE 2: COMPANY DOCUMENT TEMPLATE CENTER

Create a Document Template Center accessible according to the existing role and permission model.

Authorized users must be able to:
- Import document templates from supported files, including DOCX and PDF, and other formats only where the existing application can safely support them.
- Upload, preview, classify, version, activate, archive and download templates.
- Give every template a name, description, category, owner, version, effective date and status.
- Assign templates to the whole company or select specific departments that may use them.
- Select multiple departments for one template and manage assignments later.
- Define template usage permissions separately from template-management permissions.
- See which template is currently active for a document category and department.
- Choose an approved template when creating a supported document.
- Keep the source template unchanged and preserve the original file for download.
- Maintain version history and audit records for imports, edits, assignments, activation and archival.
- Warn users when a template is archived, outdated or not authorized for their department.

Department assignment must be enforced by backend permissions, not merely by hiding templates in the UI. Use the existing department and role schema. Do not invent departments or assume all users are administrators.
